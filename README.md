# JCB Rental Website

## Overview

This project is a JCB rental service website built using Next.js and Node.js. The platform connects customers who need JCB machinery for construction, excavation, land leveling, and other heavy-duty work with service providers.

The project is currently in the initial development phase, with frontend development in progress.

## Features (Planned)

* Responsive and modern user interface
* Service information and pricing details
* Contact form for rental inquiries
* Customer request submission
* Admin dashboard for managing inquiries
* Location-based service availability
* Mobile-friendly design

## Tech Stack

### Frontend

* Next.js
* React.js

### Backend (Planned)

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd frontend --- for frontend
cd backend --- for backend
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
